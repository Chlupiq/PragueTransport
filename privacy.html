Aplikaci Moje MHD Praha vyvíjí a provozuje Martin Molík, fyzická osoba, kontakt: martinmolik94@gmail.com. Aplikace je dostupná na platformách iPhone, iPad a Apple Watch prostřednictvím Apple App Store.

Aplikace nesbírá jméno, e-mail, telefonní číslo, platební údaje, identifikátory zařízení (IDFA, IDFV) ani jakékoliv jiné osobní údaje. Nevyužívá žádnou analytickou ani reklamní SDK.

📍3. Přístup k poloze

Aplikace žádá o přístup k poloze při používání (When In Use) pro zobrazení nejbližších zastávek a interaktivní mapy. Volitelně lze povolit polohu vždy (Always) pro automatické obnovení widgetů a Live Activity na pozadí.

GPS souřadnice jsou odeslány pouze jako parametr dotazu na API Golemio (seznam zastávek v okolí). Nejsou ukládány, agregovány ani jinak zpracovávány mimo toto jednorázové volání. Přístup k poloze lze kdykoliv odvolat v Nastavení iPhone → Soukromí a zabezpečení → Polohové služby → Moje MHD Praha.

🔗4. Třetí strany a externí API

Pro zajištění funkcí aplikace jsou odesílány síťové požadavky na níže uvedené služby. Aplikace nesdílí osobní údaje — přenáší pouze parametry nezbytné pro dotaz (poloha, ID zastávky, čas).

  • Golemio (Operátor ICT, a.s.)
    Živé odjezdy, pozice vozidel, tvary tras. Data PID v reálném čase. Přenáší se: GPS souřadnice, GTFS ID zastávek.
    Privacy →
  • Google Maps Directions API (Google LLC)
    Plánování cesty — výpočet spojení s přestupy. Přenáší se: souřadnice výchozího a cílového místa.
    Privacy →
  • PID (Pražská integrovaná doprava)
    Databáze zastávek (stops.json). Stahuje se jednorázově a aktualizuje každých 7 dní. Nepřenáší se žádná osobní data.
    Privacy →
  • OpenStreetMap / Overpass API
    Vstupy do stanic metra. Dotaz obsahuje souřadnice vybrané stanice, nikoliv polohu uživatele.
    Privacy →

🎫5. SMS jízdenky

Aplikace umožňuje nákup jízdenky PID přes SMS na číslo 90206. SMS je předvyplněna automaticky — uživatel ji odesílá sám ze své nativní aplikace Zprávy. Aplikace Moje MHD Praha SMS neodesílá, nevidí ji ani nezpracovává její obsah ani telefonní číslo uživatele. Veškerá data týkající se SMS jízdenky spravuje výhradně mobilní operátor a PID.

🍎6. Sdílení dat v rámci Apple ekosystému

Data (uložená místa, nastavení, odjezdy) jsou sdílena mezi iPhone, iPad, Apple Watch a widgety prostřednictvím App Groups (group.chlupacz.Transport-Prague) a WatchConnectivity. Sdílení probíhá lokálně v zařízení — data neopouštějí Apple ekosystém a nejsou dostupná třetím stranám.

Aplikace může využívat iCloud pro zálohu nastavení, pokud to systém iOS provede automaticky v rámci zálohování zařízení. Na tato data se vztahují Zásady ochrany soukromí Apple.

🔐7. Zabezpečení

Veškerá komunikace s externími API probíhá výhradně přes HTTPS. API klíče jsou uloženy v Info.plist aplikace a nejsou součástí kódu. Aplikace neukládá žádné citlivé osobní údaje, proto nepodléhá zvláštním požadavkům na šifrování uložených dat.

👶8. Děti

Aplikace není cílena na děti mladší 13 let a záměrně nesbírá žádné informace od dětí. Pokud zjistíte, že vaše dítě poskytlo aplikaci osobní údaje, kontaktujte nás.
